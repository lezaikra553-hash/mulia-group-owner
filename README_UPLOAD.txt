MULIA GROUP OWNER PWA

Upload SEMUA isi folder ini ke root repository GitHub/Vercel:
- index.html
- manifest.webmanifest
- sw.js
- folder icons

Jangan hanya upload index.html karena fitur instal membutuhkan manifest, service worker, dan ikon.
Situs harus dibuka melalui HTTPS (Vercel otomatis HTTPS).

Android Chrome/Edge:
1. Buka situs.
2. Login bila perlu.
3. Tekan tombol "Instal Aplikasi" atau menu browser > Instal aplikasi.

iPhone/iPad Safari:
1. Buka situs di Safari.
2. Tekan Bagikan.
3. Pilih Tambahkan ke Layar Utama.
